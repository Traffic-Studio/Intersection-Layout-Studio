# Intersection Layout Studio

Draw and present road intersections, turning flows, scenarios and externally supplied results. Intersection Layout Studio runs locally in a Chromium-based browser. It does not calculate road capacity.

## Download

Latest release: **1.2.0**. Download **intersection-layout-studio-1.2.0.html** from the [release page](https://github.com/Traffic-Studio/Intersection-Layout-Studio/releases/tag/v1.2.0).
