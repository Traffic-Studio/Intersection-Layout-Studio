# Intersection Studio

Draw and present road intersections, turning flows, scenarios and externally supplied results. Intersection Studio runs locally in a Chromium-based browser. It does not calculate road capacity.

## Download

Latest release: **1.1.0**. Download **intersection-studio-1.1.0.html** from the [release page](https://github.com/Traffic-Studio/Intersection-Studio/releases/tag/v1.1.0).
