# Quick Start — Intersection Studio 1.1.0

1. Download **intersection-studio-1.1.0.html** from the [release page](https://github.com/Traffic-Studio/Intersection-Studio/releases/tag/v1.1.0).
2. Open the downloaded HTML file in a Chromium-based browser. The core editor runs locally; the optional map background needs a network connection when enabled.
3. Create an intersection, then configure its approaches, lanes and traffic control.
4. Enter turning flows or open an existing `.istudio` project. Use the scenarios and flow diagram to compare and present the supplied values.
5. Save your project as an `.istudio` file. Keep that file if you want to continue later.
